# Pop Up Pet

This project, commonly known as "Desktop Pet", is about a little pet who pops up on the screen and reminds you to do some tasks.
For example: drink water, take a break, etc.

## Stack

- [Electron](https://www.electronjs.org/) — desktop app framework (transparent, always-on-top window)
- JavaScript / HTML / CSS — animation and UI logic
- Node.js — runtime and packaging (electron-builder)
